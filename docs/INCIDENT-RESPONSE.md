# Incident response

1. Declare severity and incident owner; preserve timestamps and evidence.
2. Contain through tenant disablement, credential rotation or traffic restriction.
3. Check health, configuration, queues, worker heartbeat, external provider status and recent release.
4. Roll back only through the documented procedure; never run destructive SQL during diagnosis.
5. Notify affected parties under contractual and legal deadlines.
6. Close with root cause, customer impact, corrective actions and evidence-retention decision.
