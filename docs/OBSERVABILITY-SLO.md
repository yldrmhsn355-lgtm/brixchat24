# Observability and SLO

Initial targets: public API availability 99.9% monthly, webhook accepted-or-rejected deterministically 99.9%, API p95 below 750 ms under the standard profile, and worker heartbeat age below 120 seconds. Page on sustained 5xx above 1%, stale heartbeats, queue backlog growth or readiness failure. Ticket sustained latency and error-budget burn. Recalibrate only from production telemetry and record the decision.
